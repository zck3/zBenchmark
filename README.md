
# zBenchmark

By Zack T Smith, 3 at zs3 dot me.

zBenchmark is a multfaceted benchmark that tests many aspects of 
a computer's performance and provides a single aggregate score.

The reference device is a 13-inch 2014 Macbook Pro with a Core i5 4278U
and 8GB of DDR3L-1600 RAM, which achieves a 1.0 score for each test and overall.

## Installation

To compile and install:

* `./configure`
* `./install.sh`
